Awareness only
Hi, I'm AarogyaSathi, your health companion. Ask about a disease, a symptom, a vaccine, or paste a forwarded message that starts with "fact check:".

Myth checks and emergency replies are instant. Written answers come from a small model on a free server and can take up to 20 seconds. Not medical advice.

How an answer is made

Every message goes through the same five steps, and the safety check always runs first.

  1. 1

    Safety check

    Rules look for emergencies and self-harm. If one matches, the reply is fixed and no LLM is called.

  2. 2

    Understand

    Language ID, a trained intent classifier and whole-word entity matching. An LLM is used only when unsure.

  3. 3

    Retrieve

    LaBSE embeddings search the curated knowledge base across English, Hindi and Hinglish.

  4. 4

    Answer or verify

    The model sees only the retrieved entry. Forwarded claims are matched to 64 curated myths first.

  5. 5

    Cite

    Each answer lists its sources and a disclaimer. With no model available, templates answer instead.

Known limits

  • The knowledge base is small, so out-of-scope questions get an honest "I don't have reliable information".
  • The demo runs a 1.7B local model on two CPU cores, so written answers are slow and plainer than a hosted model.
  • It gives awareness information only. It never diagnoses or prescribes.
